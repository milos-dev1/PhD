\section{B. API Specification}

\indent Prototype REST API (prototype/api/app.py): GET /health --- returns status and supported schemes. POST /auth/register --- body: \{device\textsubscript{id}\}; registers client key. POST /auth/handshake/init --- body: \{device\textsubscript{id}\}; returns session\textsubscript{id} and handshake data. POST /auth/handshake/complete --- body: \{session\textsubscript{id}, txn\textsubscript{nonce}\_hex\}; completes authentication. POST /settlement/submit-batch --- body: \{batch\textsubscript{id}, domain\textsubscript{id}, records[]\}; submits and verifies batch.
